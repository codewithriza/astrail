# Community conduct

Help people participate regardless of background or experience. Ask clear questions, explain technical disagreements, and give feedback about the work rather than the person.

Harassment, threats, discriminatory abuse, sexualized conduct, doxxing, and publishing private information without consent are not welcome. Do not spam issues, reviews, or discussions.

Maintainers may edit or remove disruptive content, close off-topic conversations, and restrict participation when necessary. Apply these rules consistently and explain moderation decisions when doing so does not expose private information.

Report public misconduct using GitHub's reporting tools. Avoid reposting sensitive details in public threads. Security vulnerabilities follow `SECURITY.md`.
